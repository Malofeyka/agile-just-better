# Agile Just Better

Кликабельный MVP таск-трекера для небольших команд. Каждая функция закрывает одну из проблем YouGile, которые команда нашла на этапе As-Is. Сама задача описана в [TASK.md](TASK.md).

Это прототип: данные хранятся в `localStorage` браузера, сервера нет. ИИ-помощник работает локально на правилах, без внешнего API.

## Запуск

```bash
npm install
npm run dev
```

Сборка для хостинга: `npm run build` → папка `dist/`. При пуше в `main` GitHub Actions выкладывает сборку на GitHub Pages.

## Какие проблемы и чем закрыты

| # | Проблема (As-Is) | Решение в прототипе |
|---|---|---|
| 1 | Статусы не обновляют | Кнопка «Начать»/«На проверку»/«Готово» на карточке; напоминания о зависших задачах |
| 2 | Мало автоматизации | Готовые правила: автоназначение ревьюера, напоминания, лог переносов дедлайна |
| 3 | Информация разбросана | База знаний и материалы (ссылки) прямо в задаче |
| 4 | Дублирование работы | Предупреждение о похожих задачах при создании и в карточке |
| 5 | Не виден вклад | Экран «Вклад»: ревью, помощь, снятые блокеры, а не только закрытые задачи |
| 6 | Проблемы видны поздно | Экран «Спринт»: блокеры, зависшие задачи, прогноз успеваемости |
| 7 | Ретро без результата | Пункт ретро одной кнопкой превращается в задачу |
| 8 | Перегруженный интерфейс | Простая доска, автоматизации включаются переключателем |
| 9 | Неполные ТЗ | Шаблон ТЗ (цель, критерии, детали) и индикатор полноты |
| 10 | Срываются дедлайны | Перенос дедлайна требует причину и попадает в историю; панель дедлайнов |
| 11 | Нет единой аналитики | Дашборд спринта на одном экране + ИИ-сводка |
| 12 | Мотивация | Прозрачный учёт вклада каждого |
| 13 | Мобильная версия | Адаптивная вёрстка |
| 14 | Сложный переезд | Импорт задач списком или CSV из Trello/Jira/YouGile |

## Для тестирования MVP

На экране «Аналитика» видно, какие функции используют тестировщики. После теста нажмите «Выгрузить JSON» и сведите метрики. Кнопка «Сбросить к демо» на экране «Автоматизации» возвращает исходные данные.
